# Использование ИИ

## Инструменты и делегированные задачи

Cursor (Grok): поиск дефектов, правки PHP/React и проверки. Код принят после прогона тестов.

## Один существенный пример

Контекст: PHP 7.4 без фреймворка, PostgreSQL, React. Задержки API не убирать.

Запрос: найти причины трёх ошибок и исправить смену источника — права на сервере, `source: null`, транзакция с историей, игнор устаревших ответов.

Изменение: `LEFT JOIN` и `source: null` в `TicketRepository.php`; `FUNC_TICKETS_SOURCE_EDIT` и порядок «заявка → архив → источник»; `UPDATE` и история в одной транзакции; в `TicketPanel.jsx` ответ применяется только к текущему поколению запроса.

## Проверка результата

`python3 tools/test_api.py http://localhost:5173`: заявка 103 отвечает 200 с `source: null`; POST от viewer — 403, данные не меняются.

Отклонено: убирать `DEMO_LATENCY` и добавлять PHP-фреймворк.
